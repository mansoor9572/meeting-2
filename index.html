Machine Learning Models in Web Applications: A Comprehensive Review

Kajian komprehensif mengenai strategi integrasi machine learning pada arsitektur web modern, perbandingan framework backend, peningkatan Web Application Firewall (WAF), serta alur kerja MLOps dan keamanan siber adaptif.

Penulis Kshiteesh Mani & Ajitha K.B. Shenoy
Afiliasi Manipal Institute of Technology, MAHE
Publikasi / Penerbit ICT Express, Vol. 11 (Elsevier)
Substansi Penelitian

Apa yang Dibahas dalam Paper?

Paper ini membedah empat pilar utama integrasi machine learning dalam ekosistem aplikasi web modern.

01

Python vs Node.js Stack

Analisis perbandingan backend untuk inferensi model:

  • • Python (Flask, Django): Raja ekosistem data science, kaya pustaka (Scikit-Learn, PyTorch, Keras), ideal untuk model kompleks dan microservice terpisah.
  • • Node.js (TensorFlow.js, Brain.js): Arsitektur non-blocking asynchronous yang unggul dalam I/O latency rendah, unified full-stack JS, cocok untuk inferensi ringan real-time.
02

ML & DL pada WAF (Firewall)

Transformasi Web Application Firewall dari rule berbasis signature ke AI adaptif:

  • • Deteksi anomali HTTP traffic (analisis n-gram karakter, TF-IDF, panjang request, dan entropy).
  • • Penggunaan SVM, Random Forest, CNN, dan Autoencoder untuk memitigasi SQL Injection (SQLi), Cross-Site Scripting (XSS), dan zero-day payload.
03

MLOps & Arsitektur Deployment

Tantangan menjembatani fase riset data science ke produksi web:

  • • Kontainerisasi dengan Docker dan orkestrasi via Kubernetes guna auto-scaling inferensi model.
  • • Pipeline CI/CD terintegrasi, penanganan data drift, serta pemeliharaan zero-downtime serving.
04

Studi Kasus & Tren Industri

Implementasi di skala enterprise nyata:

  • • Google Cloud Armor: Penerapan model ML untuk mitigasi serangan DDoS dan layer-7 otomatis.
  • • Netflix Foundation Model: Personalisasi konten multi-modal secara berskala global.
  • • Federated Learning: Menjaga privasi data pengguna tanpa mentransfer data mentah ke cloud.

Kekuatan Paper (Strengths)

Aspek-aspek unggul yang membuat tinjauan literatur ini berharga bagi pengembang dan peneliti keamanan.

✓

Perspektif Ganda Terpadu

Tidak hanya mengupas sisi software engineering (backend, framework web), tetapi juga mengintegrasikannya dengan pilar cybersecurity (WAF, deteksi intrusi web).

✓

Perbandingan Stack Realistis

Menganalisis Python vs Node.js secara objektif sesuai trade-off: kematangan ekosistem analitik Python vs efisiensi konkurensi event-driven Node.js.

✓

Relevansi Industri & MLOps

Membawa pembaca melampaui teori akademik dengan menyoroti praktik MLOps, CI/CD, kontainerisasi, serta arsitektur cloud enterprise.

Evaluasi Kritis

Kelemahan & Limitasi Paper

Ruang evaluasi dan batasan metode yang ditemukan dalam paper untuk pertimbangan riset lanjutan.

!

Kompilasi Sekunder Murni

Paper ini murni berupa systematic literature review tanpa menyajikan eksperimen laboratorium independen, implementasi prototipe baru, atau dataset uji orisinal.

!

Minim Benchmark Kuantitatif

Tidak ada data komparasi numerik langsung head-to-head (misal: RPS, latency p99, memory footprint) antara Python (WSGI/ASGI) dan Node.js pada beban inferensi identik.

!

Solusi Adversarial Belum Tuntas

Serangan adversarial terhadap WAF (seperti GenXSS dan AdvSQLi) baru diposisikan sebagai tantangan terbuka di masa depan tanpa rekomendasi mekanisme mitigasi konkret.

Kesimpulan Ringkas

Panduan Memilih Antara Python dan Node.js untuk Web ML

Gunakan Python saat membutuhkan ekosistem training yang matang, model deep learning berat, atau arsitektur microservices. Pilih Node.js ketika aplikasi membutuhkan throughput I/O tinggi, event-driven streaming, dan inferensi ringan on-the-fly.
